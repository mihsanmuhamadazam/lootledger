## ✨ Features

### 🎯 Valorant Skin Tracking
- 100+ popular skins with auto-fill VP costs
- Includes bundles like Elderflame, Prime, Reaver, Champions editions
- Track your account value and total spending

### 🔫 CS:GO / CS2 Inventory
- 90+ skins database with market prices
- **Price history charts** with 3M / 6M / 1Y views
- StatTrak™ price multipliers
- Profit/Loss tracking per skin
- Direct links to Steam Market

### 💳 Subscription Gaming
- Track Xbox Game Pass, PlayStation Plus, EA Play, etc.
- Monthly & yearly cost calculations
- Renewal reminders

### 📊 Game Worth Calculator
- Calculate RM/hour for any game
- Determine if your purchases are "worth it"
- Track completion status

### 🏆 Friends & Leaderboard
- Share your profile with unique friend codes
- Compare spending with friends

### 🔔 Sale Notifications
- Get notified about upcoming sales
- Night Market, Winter Sales, and more

## 🚀 Tech Stack

- **Frontend**: React 18 + TypeScript
- **Build**: Vite
- **Styling**: Tailwind CSS with custom gaming theme
- **State**: TanStack Query + React Router
- **Storage**: IndexedDB (local-first)
- **Charts**: Chart.js + react-chartjs-2
- **Animations**: Framer Motion
- **Icons**: Lucide React

## 💰 Currency

All prices are displayed in **Malaysian Ringgit (RM)**

## 🛠️ Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📦 Deployment

### Vercel (Recommended)

1. Fork this repository
2. Connect to Vercel
3. Deploy! (auto-detects Vite)

### Manual

```bash
npm run build
# Deploy the `dist` folder
```
